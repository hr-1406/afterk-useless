# Productivity Punisher 🎯


## Basic Details
### Team Name: AfterK

### Project Description
An evil Chrome extension that violently punishes you for being productive instead of procrastinating. If you do work on productive sites, you lose points. If you procrastinate on sites like YouTube and Instagram, you gain points! Reach 0 points, and you are forced into an inescapable 5-minute YouTube punishment!

### The Problem (that doesn't exist)
People are being far too productive and doing too much work, which is ruining their perfectly good procrastination time. There are simply too many tools helping people stay focused, and not enough tools forcing them to waste time.

### The Solution (that nobody asked for)
Reverse productivity tracking! We actively monitor your browsing and penalize you for visiting productive sites like GitHub, ChatGPT, or Wikipedia. If your score drops to zero, the extension takes over your browser and forces you to watch specific, unskippable YouTube videos for 5 minutes straight. Try to close the tab? We'll just open a new one!

### Implementation
For Software:
# Installation
1. Clone the repository
2. Open Chrome and navigate to `chrome://extensions`
3. Enable "Developer mode" in the top right corner
4. Click "Load unpacked" and select the `productivity-punisher/extension` folder

# Run
1. Open a new tab or click the extension icon.
2. Watch as your points drain whenever you try to be productive.
3. Don't let your score reach zero, or suffer the consequences!
